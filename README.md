PROJECT TITLE:
To-Do List Manager

PROJECT NUMBER:
P03

PROGRAMMING LANGUAGE:
Python 3

PROJECT DESCRIPTION:
A terminal-based application that helps students manage
daily tasks by recording their titles, priorities, due dates,
and completion status.

FEATURES:
1. Add tasks with automatically generated IDs.
2. Edit existing tasks.
3. Delete tasks after confirmation.
4. Mark tasks as completed.
5. Display pending tasks by priority and due date.
6. Identify overdue tasks and calculate days late.
7. Display tasks due within the next seven days.
8. Show task statistics.
9. Store task information in a text file.

DATA STORAGE:
tasks.txt

RESTRICTIONS:
The program uses core Python without imports,
external libraries, databases, or GUI frameworks.

HOW TO RUN:
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run: python main.py
